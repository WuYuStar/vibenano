# VibeNano 1.1.4

修复 Windows 11 长时间挂机或经历锁屏、休眠、任务栏/全屏切换后，录音悬浮胶囊虽正常渲染但因系统 Z-Order 掉层而被普通应用窗口遮挡的问题。现在仅在录音浮层由隐藏变为显示或重新进入激活态时，事件驱动地调用一次无焦点 `SetWindowPos(HWND_TOPMOST)` 将浮层恢复到最顶层，待机零额外开销且不抢占输入焦点。

完整解压便携 ZIP，完全退出旧版，再运行 `VibeNano win版 1.1.4.exe`。所有配置、按键映射与 Fun-ASR-Nano 模型继续保存在程序旁的 `data` 目录中；升级时保留原有的 `data` 目录即可直接复用，无需重新下载模型。

Windows x64 未签名便携版，模型权重与 VB-CABLE 驱动不随包提供。本项目为 GPL-3.0-only 衍生版，保留原作者版权与署名；[Qt/PySide6 对应源码](https://github.com/WuYuStar/vibenano/releases/tag/third-party-source-qt-6.11.1) 保持可用。
