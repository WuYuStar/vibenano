# VibeNano 1.0.109

修复上一版仍向旧 RemoteMic 用户目录写入权限登记、设备符号缓存的问题，统一改用 VibeNano。

完整解压便携包，完全退出旧版，再运行 `VibeNano win版 1.0.109.exe`。设置和 Nano 模型继续使用 `%LOCALAPPDATA%\VibeNano\RC003`，无需重新下载。旧目录的数据导入能力保留，但运行中的新版不会再向旧用户目录登记或写入缓存。

本次完成迁移、权限登记、设备缓存路径的针对性检查，并对实际打包程序进行启动和 Qt 运行检查；不代替实体遥控器的长期使用验收。

Windows x64 未签名便携版，模型权重与 VB-CABLE 驱动不随包提供。本项目为 GPL-3.0-only 衍生版，保留原作者版权与署名；对应源码随本次发布提供，[Qt/PySide6 对应源码](https://github.com/WuYuStar/vibenano/releases/tag/third-party-source-qt-6.11.1) 保持可用。
