# VibeNano 1.1.3

修复 Windows 11 默认硬件渲染（D3D11）下录音悬浮动画窗口透明不可见的问题，使按住录音波形和识别旋转动画正常显示，同时保留 1.1.2 的纯便携数据目录、事件驱动状态更新和精简日志优化。

完整解压便携 ZIP，完全退出旧版，再运行 `VibeNano win版 1.1.3.exe`。所有配置、按键映射与 Fun-ASR-Nano 模型继续保存在程序旁的 `data` 目录中；升级时可将原有的 `data` 目录复制到新版文件夹旁直接复用，无需重新下载模型。

Windows x64 未签名便携版，模型权重与 VB-CABLE 驱动不随包提供。本项目为 GPL-3.0-only 衍生版，保留原作者版权与署名；[Qt/PySide6 对应源码](https://github.com/WuYuStar/vibenano/releases/tag/third-party-source-qt-6.11.1) 保持可用。
