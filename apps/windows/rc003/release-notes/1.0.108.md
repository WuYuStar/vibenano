# VibeNano 1.0.108

- 软件显示名、窗口和主程序文件名统一为 VibeNano。
- 新数据目录为 `%LOCALAPPDATA%\VibeNano\RC003`；首次启动在旧版退出后导入旧设置并复用完整的 Nano 模型，不覆盖新目录已有文件，旧目录保留备份。
- 程序内更新入口改为本仓库，兼容旧版文件名和共享权限组件。

## 使用

下载并完整解压便携 ZIP，从托盘完全退出旧版，再运行 `VibeNano win版 1.0.108.exe`。已有模型无需重新下载；首次下载在“语音”页查看进度。旧 RemoteMic 数据目录暂时不要删除。

本包为 Windows x64 未签名便携版，不含模型权重或 VB-CABLE 驱动。外部输入法用户可从 [VB-Audio 官网](https://vb-audio.com/Cable/) 安装驱动；Nano 本地识别无需该驱动。CPU 需要支持 AVX2/F16C/FMA。

## 验证范围

155 项迁移、配置、产品身份及更新检查通过；17 项界面加载和共享权限组件检查通过。实际打包程序的 `--dry-run` 和 `--qt-runtime-check` 均正常结束。本次未额外执行实体遥控器、真实用户数据迁移或长期语音录入验收。

本项目是基于 ZSTDJan/windows-remote-mic-app 与 nijez/open-voice-bridge 的 GPL-3.0-only 衍生版，保留原作者版权与署名。完整对应源码随本次 Release 提供；Qt/PySide6 6.11.1 对应源码见 [第三方源码发布](https://github.com/WuYuStar/vibenano/releases/tag/third-party-source-qt-6.11.1)。
