# 中英文混合识别模型调研

日期：2026-11-09。范围：现有 faster-whisper 与 Paraformer 流式引擎之外的本地候选。仅查阅官方模型卡、代码仓库和技术报告；没有下载新模型、安装新依赖、运行候选模型或修改应用源码。

## 用户场景与评价方式

中文句子中夹英文技术词（agent、Python、API、GitHub、Docker、Whisper），以及单独读出 A、B、C 或逐个字母拼写。这些场景需要分别评价，不能由“支持中文和英文”推断全部准确。

建议用同一批真实遥控器录音比较：英文术语保留率、中文识别错误、中途语言切换、缩写与单字母识别、静音误输出、松开到出字延迟、实际内存占用。分别测有热词和无热词，防止热词导致无关录音误输出。合成语音只适合初筛，不能代表用户口音和遥控器收音。

## 官方资料与候选

1. Fun-ASR-Nano-2512：800M，官方具体检查点支持中文、英文、日文。官方模型卡提供 hotwords 参数，并注明可选择 CPU；支持专业词汇提示是其作为本场景候选的理由。模型卡部分“31语言”概述属于整个系列/MLT版本，不能套到普通 Nano；不能由宣传“实时”推断在本项目 Windows CPU 上已有原生流式实现。
   - https://huggingface.co/FunAudioLLM/Fun-ASR-Nano-2512
   - https://github.com/QwenAudio/Fun-ASR
2. Qwen3-ASR-0.6B / 1.7B：官方训练报告强调中英文训练和上下文偏置；0.6B-hf 模型卡明确提供上下文/领域词汇提示。可作为术语识别对照。当前官方已有 Transformers 原生版本，不等于项目现有固定依赖可直接兼容。官方高吞吐/低首字延迟来自服务端/GPU测试，不能用于承诺本机 CPU 延迟。
   - https://huggingface.co/Qwen/Qwen3-ASR-0.6B-hf
   - https://arxiv.org/html/2601.21337v1
   - https://github.com/QwenLM/Qwen3-ASR
3. SenseVoiceSmall：官方提供中文、英文等语言识别，非自回归结构，提供 ONNX 导出路线。适合作为桌面 CPU 速度优先的候选。官方的70ms/10秒及倍数宣传不代表用户电脑；所查资料未建立它对 agent 或中英混说优于上述候选的结论。Small 的语言数也不能与整个 SenseVoice 系列混同。
   - https://huggingface.co/FunAudioLLM/SenseVoiceSmall
4. FireRedASR2-AED / LLM：官方明确支持中文、英文、code-switching，可列为额外准确率对照。公开普通话/方言榜单不等于中英混说或技术词榜单，不据此宣布本场景最优；部署和运行成本需另测。
   - https://github.com/FireRedTeam/FireRedASR2S

## 针对本机的建议（推断，尚未实测）

只读系统查询：i5-1340P，约16GB内存，Intel Iris Xe核显，未看到NVIDIA独显。

优先比较 Fun-ASR-Nano-2512（含技术词热词）与 Qwen3-ASR-0.6B；保留 SenseVoiceSmall 作为轻量速度对照。1.7B和FireRed暂不列入本机首轮。准确率排序、CPU速度和Windows便携包兼容性均需要实测后决定。

agent 是常见英文词，有合理的识别预期，但尚无本机实测可保证；A/B/C、API逐字母和项目名称另测。热词是识别提示，不是固定替换，更不应把所有近音中文强制替换成英文词。

候选功能：增加可编辑的技术词热词表，以及第三个可选本地识别引擎；等待用户选定后实施。
